# MediaPlayController 实现清单

> 按功能点拆分，每完成一个功能编译一次，确保不破坏播放。

---

## 功能一：初始化管线（打开视频）

**目标**：`Initialize()` 跑完，所有组件就绪，准备好播放。

- [ ] 头文件补 `#include <QThread>`、`#include <QWidget>`，去重 include guard
- [ ] 创建 4 个队列（带 max_size 和 AVPacket/AVFrame 的 deleter）
- [ ] 创建所有组件：demuxer → A/V decoder → AudioPlayer → VideoRender → syncmanager
- [ ] 创建 4 个线程，组件 moveToThread
- [ ] 调 decoder 的 `initDecoder()`、AudioPlayer 的 `initAudioPlay()`、VideoRender 的 `initvideoRender()`
- [ ] `CreateConnections()`：4 个 `thread::started → 组件::workFunction` 的 connect
- [ ] VideoRender 嵌入 `rendererContainer` 的 layout

**代码来源**：MainWindow 构造函数(28-68行) + createConnect(72-79行) + 匿名namespace(4-10行)

---

## 功能二：播放 / 暂停 / 停止

**目标**：三个方法实现完，能跑通最基础的播放控制流程。

- [ ] `Start()`：各组件 `start()` → 4 个 thread `start()` → `m_videoRender->startRendering()`
- [ ] `Pause()`：各组件 `pause()` + `m_videoRender->pause()`
- [ ] `Stop()`：4 个队列 `SetStopFlag(true)` + `WakeAll()` → 各组件 `stop()` → `m_videoRender->stopRendering()`

**代码来源**：MainWindow start(176-189行) / pause(195-200行) / closeEvent(126-141行)

---

## 功能三：音量调节

**目标**：键盘上下键能调音量。

- [ ] `VolumeUp()` → `m_audioplay->volumeUp()`
- [ ] `VolumeDown()` → `m_audioplay->volumeDown()`

---

## 功能四：快进 / 快退

**目标**：键盘左右键能 seek。

- [ ] `Forward()`：pause → `m_syncManager->Forword()` → start
- [ ] `Rewind()`：同理，调 demuxer 的 seek（当前 MainWindow 里 Left 键只 emit 了一个信号但没实际逻辑，需要补上：pause → demuxer->Rewind() → start）

**代码来源**：MainWindow keyReleaseEvent 159-165行

---

## 功能五：资源释放

**目标**：Controller 析构时干净回收所有线程和组件。

- [ ] `ReleaseResources()`：4 个 thread `quit()` + `wait()` + `delete` → delete 5 个组件
- [ ] 析构函数里调 `ReleaseResources()`

**代码来源**：MainWindow freeRsources(209-229行)

---

## 功能六：MainWindow 瘦身

**目标**：MainWindow 只留 UI，所有播放逻辑转发到 Controller。

- [ ] `mainwindow.h`：删基础设施层 include，只留 `MediaPlayController.h`；删所有播放管线成员变量；新增 `MediaPlayController* m_controller`
- [ ] 构造函数精简为：创建 controller → 创建 FileMediaSource → open → `m_controller->Initialize()`
- [ ] `start()` / `pause()` / `stop()` 改为转发到 controller
- [ ] `VolumeUp()` / `VolumeDown()` 改为转发到 controller
- [ ] `keyReleaseEvent()` 改为调 controller 对应方法
- [ ] `closeEvent()` 精简为一行 `m_controller->Stop()`
- [ ] 删掉 `freeRsources()` 和 `createConnect()` 方法
- [ ] 头文件里 `#include "infrastructure/..."` 全部移走时加 `#include <QKeyEvent>`（现在靠 demuxer.h 间接带进来的）
